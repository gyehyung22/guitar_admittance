# Methods and Implemented Theory

This document describes the implementation represented by the `mixed-v6` source
snapshot. It distinguishes the canonical dataset path from reference solvers,
ablations, and experimental neural architectures.

## 1. Problem Definition

For each guitar body, material, and bridge drive point, the pipeline estimates the
driving-point mechanical admittance

```math
Y(\omega) = \frac{v_z(\omega)}{F_z(\omega)}
            = \frac{i\omega u_z(\omega)}{F_z(\omega)}.
```

The harmonic convention is `exp(+i omega t)`. Geometry is built in millimetres,
while all FEM operators and response units use SI. The canonical neural target is
`20 log10 |Y|` in dB relative to `1 m/s/N`.

The v6 dataset realizes each base contour twice:

- `solid`: structural dynamics only, solved by full harmonic FEM.
- `hollow`: wood structure, enclosed air, and an impedance soundhole port, solved
  by a reduced projection of the two-way coupled FEM system.

Semi-hollow construction exists in the CAD code but is not part of the v6 dataset
contract.

## 2. Deterministic Geometry Sampling

### 2.1 Body contours

The first eight base shapes are canonical guitar outlines in `guitar_shapes.py`.
The remaining shapes are generated by `shape_gen.py` from irregular radial control
polygons, periodic interpolation, and size/aspect normalization. Production contours
contain 120 points.

Random shapes vary control-point count, angular spacing, radial perturbation,
non-convex pulls, interpolation type, height, and aspect. Degenerate candidates have
an ellipse fallback. Geometry placement is deterministic because each object obtains
an independent RNG from a SHA-256 hash of the master seed and semantic tags. Adding
or retrying one object therefore does not shift all later random draws.

### 2.2 Body and plate dimensions

The v6 production ranges are:

```text
body thickness          Uniform(40, 55) mm
top-plate thickness     Uniform(3.0, 6.5) mm, hollow only
side-wall thickness     5.0 mm
back-plate thickness    2.0 mm
top and back type       flat
bracing                  none
```

Top-plate thickness is sampled directly. The legacy cavity-depth parameter is
derived once:

```math
r_{cavity} = 1 - \frac{t_{top}}{t_{body}}.
```

The CAD builder verifies that the resulting top plate equals the requested value.
Solid rows carry zero cavity and soundhole features in the NN contract.

### 2.3 Bridge and soundhole placement

Ten bridge points are sampled inside the outer polygon. Each must remain at least
10 mm from the body edge after deterministic fallback through progressively less
restrictive placement margins. Every point is embedded in the top surface during
meshing, so the drive is an exact mesh node rather than an arbitrary nearest-node
approximation.

The production hollow soundhole is circular. Its diameter is sampled between 30 and
80 mm. The complete rim must remain at least 20 mm inside the body, and every bridge
point must stay at least 5 mm outside the hole rim. These are geometric validity
constraints, not acoustic tuning constraints.

### 2.4 Coordinate frames

The placement frame is body-centred with positive Y toward the neck. The direct
CadQuery/STEP/FEM frame negates Y. `dataset_gen.py` creates direct contour, bridge,
and soundhole fields in the STEP frame and also retains legacy raster fields. The
direct fields are authoritative and avoid a bitmap-to-contour round trip.

## 3. Orthotropic Wood

### 3.1 Sampled engineering constants

Each v6 base shape receives its own bank of ten random materials. No fixed reference
material is inserted. The sampled quantities are the three Young's moduli, three
shear moduli, three major Poisson ratios, and density:

| Quantity | Range |
|---|---:|
| `E_L` | 8 to 14 GPa |
| `E_R` | 0.8 to 2.5 GPa |
| `E_T` | 0.4 to 1.0 GPa |
| `G_LR`, `G_LT` | 1.0 to 1.8 GPa |
| `G_RT` | 0.05 to 0.30 GPa |
| `nu_LR`, `nu_LT` | 0.30 to 0.50 |
| `nu_RT` | 0.30 to 0.60 |
| density | 300 to 700 kg/m3 |

### 3.2 Poisson reciprocity and positive definiteness

The compliance tensor is assembled symmetrically. For example,

```math
S_{LR}=S_{RL}=-\nu_{LR}/E_L,
```

which implicitly enforces the reciprocal minor ratio through

```math
\frac{\nu_{LR}}{E_L}=\frac{\nu_{RL}}{E_R}.
```

The same construction is used for the other normal-direction pairs. Shear
compliances are `1/G`. A candidate is accepted only if the symmetric compliance
matrix is positive definite. The stiffness is then `C = S^{-1}`. This rejection
step prevents non-physical random combinations even when each scalar lies inside
its marginal range.

Material directions are fixed to the global body frame: longitudinal grain `L` is
`+Y`, radial `R` is `+X`, and tangential `T` is `+Z`. The Voigt tensor is permuted
accordingly before assembly.

## 4. CadQuery Solid Modelling

`backend/model_builder.py` fits a periodic spline to the direct 120-point contour
and creates the outer solid by extrusion.

For a hollow body:

1. Shapely computes a true parallel inward offset of the contour by 5 mm.
2. The cavity starts above the fixed 2 mm back plate.
3. The cavity stops below the top surface so that the requested top-plate thickness
   remains.
4. The cavity is subtracted from the wood.
5. A circular soundhole is cut through the top plate only.
6. The exact cavity negative volume is exported as a second STEP solid.

The internal air STEP includes the cavity but not an explicit soundhole neck. Neck
inertance and exterior radiation are represented by the lumped sound-port model.
CadQuery volume and plate measurements are recorded for later mesh cross-checks.

## 5. Gmsh Meshing

### 5.1 Structural mesh

The structural domain uses first-order tetrahedra. Production solid sizing is 4 to
6 mm. Bridge vertices are projected to and embedded in the top face. The body volume
and bridge points receive stable physical tags.

### 5.2 Conformal wood-air mesh

For hollow bodies, the wood and air STEP solids are imported into one Gmsh OCC model
and passed through `BooleanFragments`. This creates distinct wood and air tetrahedral
cells with a shared triangulation on every fluid-structure interface.

Conformal does not mean that the air and wood have the same volume-element size.
Only the common boundary faces and nodes match exactly. Production targets are:

```text
wood maximum                  6.0 mm
top/back plate target         clamp(plate thickness / 2, 1.5, 6.0) mm
air interior                  10.0 mm
soundhole vicinity             3.0 mm
```

This gives about two elements through a plate while allowing the air mesh to coarsen
away from the interface. Gmsh uses its 3D Delaunay algorithm followed by Netgen mesh
optimization.

Physical tags distinguish wood, internal air, top/back/side FSI surfaces, the open
soundhole, exterior wood surfaces, and bridge vertices. Before writing the mesh, a
fail-closed gate checks:

- every FSI surface has exactly one adjacent wood and one adjacent air volume;
- the open soundhole is an air-only boundary in the expected plane and position;
- no volume or relevant surface is unassigned;
- CAD volume, soundhole area, plate position, and cavity geometry agree with the
  planned values within contract tolerances.

## 6. Structural Finite Elements

### 6.1 Weak form

The displacement field uses first-order vector Lagrange elements. With small-strain
linear elasticity,

```math
\epsilon(u)=\tfrac12(\nabla u+\nabla u^T), \qquad
\sigma(u)=C:\epsilon(u).
```

The assembled operators are

```math
K_{ij}=\int_{\Omega_s}\epsilon(N_i):C:\epsilon(N_j)\,d\Omega,
\qquad
M_{ij}=\int_{\Omega_s}\rho N_i\cdot N_j\,d\Omega.
```

There are no Dirichlet boundary conditions. The body is free-free.

### 6.2 Mesh-independent weak spring

A free-free stiffness has six rigid-body null modes. Rather than clamp the body, a
small diagonal grounding spring places those modes near 1 Hz, below the 20 Hz target
band. Its per-DOF stiffness is scaled from total FEM mass and node count:

```math
k_w=(2\pi f_r)^2\frac{M_{total}}{N_{nodes}}, \qquad f_r=1\ \mathrm{Hz}.
```

This preserves the intended free response in band and avoids a mesh-dependent fixed
spring constant.

### 6.3 Rayleigh damping and harmonic solve

The damping matrix is

```math
C_d=\alpha M+\beta K, \qquad \alpha=0,\quad \beta=5\times10^{-6}\ \mathrm{s}.
```

At each angular frequency, the dynamic system is

```math
Z_s(\omega)u = F,
\qquad
Z_s=K_w-\omega^2M+i\omega(\alpha M+\beta K_w),
```

where `K_w` denotes the elastic stiffness with the weak spring included. A 1 N load
is applied in global Z at each bridge point. PETSc complex matrices and MUMPS sparse
LU solve all bridge right-hand sides for a frequency together.

The production solid response uses this full harmonic solution at all 500 frequency
bins. It is not reconstructed from modal residues.

The sparse pattern is fixed across frequency, so PETSc/MUMPS can reuse symbolic
analysis. The frequency-dependent matrix still requires numerical refactorization at
each bin. Multiple bridge loads are solved as multiple right-hand sides against the
same factorization.

## 7. Structural Eigensolution and Phase-Safe Realification

SLEPc solves the generalized Hermitian problem

```math
K_w\phi_n=\omega_n^2M\phi_n
```

with Krylov-Schur shift-invert and MUMPS. PETSc may return a complex representation
of a physically real eigenspace with arbitrary phase. Taking only `Re(phi)` after
normalizing the complex vector can destroy its mass normalization or nearly erase a
mode when the phase is close to `pi/2`.

`modal_eigenbasis.py` therefore:

1. groups equal or near-degenerate eigenvalues;
2. collects real and imaginary candidates from each group;
3. performs rank-revealing M-orthonormalization;
4. applies a projected Rayleigh-Ritz solve using K;
5. verifies residuals and `Phi.T M Phi` before accepting the basis.

This handles arbitrary phase and rotated bases inside degenerate eigenspaces. The
solid peak-label path streams eigenvalue groups, retaining only bridge participation
after full-vector checks to reduce memory.

Rayleigh damping implies the modal ratio

```math
\zeta_n=\frac{\alpha}{2\omega_n}+\frac{\beta\omega_n}{2},
\qquad Q_n=\frac{1}{2\zeta_n}.
```

The eigensolution provides clean solid resonance candidates and Q labels, while the
full harmonic solve supplies the canonical spectrum and exact candidate amplitudes.

## 8. Internal-Air Acoustics

The cavity pressure uses first-order scalar Lagrange elements. With sound speed `c`,

```math
K_a=\int_{\Omega_a}\nabla N_p\cdot\nabla N_p\,d\Omega,
\qquad
M_a=\int_{\Omega_a}N_pN_p\,d\Omega,
```

and the rigid-wall Helmholtz block is

```math
Z_a(\omega)=K_a-\frac{\omega^2}{c^2}M_a.
```

Air defaults are `c = 343 m/s` and `rho_0 = 1.204 kg/m3`.

## 9. Two-Way Fluid-Structure Coupling

Let `n_a` be the normal pointing outward from the air cavity into the wood. The
interface matrix is

```math
G_{ji}=\int_{\Gamma_{sa}}N_j^p(N_i^u\cdot n_a)\,d\Gamma.
```

The code integrates the P1 triangular facet mass matrix and checks both integrated
surface area and normal closure. Because the mesh is conformal, pressure and
displacement traces share the same interface triangles, although their volume meshes
can have different interior sizes.

The full frequency-domain Everstine displacement-pressure system is

```math
\begin{bmatrix}
Z_s & -G^T\\
-\rho_0\omega^2G & Z'_a
\end{bmatrix}
\begin{bmatrix}u\\p\end{bmatrix}
=
\begin{bmatrix}F\\0\end{bmatrix}.
```

This is a simultaneous, monolithic two-way solve. It does not alternate structure
and air iteratively. Pressure loads the wood through `G.T p`; wall normal
acceleration excites the air through `rho_0 omega^2 G u`. The block system is
physically unsymmetric in this `u-p` formulation and is solved with a general complex
LU, not a symmetric-positive-definite solver.

`fenics_admittance_coupled.py` is the full coupled reference, called backend D in
the development history. It supplies the same assembled operators used by the
production reduced solver.

## 10. Soundhole Impedance Port

The production soundhole is neither a pressure-release boundary nor a post-processing
Helmholtz peak added to the structural response. It is a nonlocal, lumped impedance
inside the coupled acoustic matrix.

Define

```math
b_j=\int_{\Gamma_h}N_j^p\,d\Gamma, \qquad S=\sum_j b_j,
```

so average pressure and volume flow are

```math
\bar p=\frac{b^Tp}{S}, \qquad U_h=\frac{\bar p}{Z_h}.
```

For effective radius `r = sqrt(S/pi)`, the port model uses neck length plus end
correction, acoustic inertance

```math
M_h=\rho_0L_{eff}/S,
```

and low-`ka` radiation resistance:

```math
Z_h(\omega)=R_{rad}(\omega)+i\omega M_h.
```

Static condensation of the scalar port-flow degree of freedom adds a rank-one term:

```math
Z'_a=Z_a+\kappa(\omega)bb^T,
\qquad
\kappa=\frac{i\omega\rho_0}{S^2Z_h(\omega)}.
```

The analytic rigid-cavity check is

```math
f_H=\frac{c}{2\pi}\sqrt{\frac{S}{VL_{eff}}}.
```

The production port uses the configured exterior end correction without double
counting the cavity-side contribution already represented by the FEM cavity. The
analytic estimate remains a diagnostic; the labelled A0 behavior comes from the
coupled harmonic response, including compliant walls.

## 11. Reduced Coupled Solver E

The production hollow backend E projects the same D operators. It does not change
the coupling physics.

### 11.1 Acoustic basis

The rigid-wall Neumann acoustic stiffness has a constant-pressure nullspace. The
solver inserts the exact mass-normalized constant mode

```math
\psi_0=1/\sqrt{V}
```

instead of trusting a numerically polluted zero eigenvector. This mode represents
cavity compliance and is essential for the A0 resonance. Elastic cavity modes are
M-orthonormalized against it.

Production also adds a sound-port attachment field by solving a constrained
quasi-static problem of the form

```math
K_ax + \lambda M_a\mathbf{1}=b,
\qquad \mathbf{1}^TM_ax=0.
```

This attachment enriches the acoustic basis near the hole. It is not the physical
port impedance: the rank-one `kappa b b.T` term still supplies the neck and radiation
physics in every reduced frequency solve.

### 11.2 Structural basis and Craig-Bampton-style attachments

Retained structural normal modes are enriched with static response fields for the
actual load paths:

```math
K_w^{-1}e_b
```

for each bridge load and

```math
K_w^{-1}G^T\psi_j
```

for selected acoustic basis vectors. Retained modal content is removed by the
normalization-independent M projection

```math
X_r=X-\Phi(\Phi^TM\Phi)^{-1}\Phi^TMX,
```

then the remaining attachment fields are M-orthonormalized against the modes and one
another.

The code calls this `craig-bampton` because it is component-mode/static-attachment
enrichment. More precisely, it is Craig-Bampton-style residual attachment, not the
classical fixed-interface Craig-Bampton formulation with explicit interface
constraint coordinates. This distinction matters when comparing methods.

### 11.3 Projection and dense sweep

With `u = Q q` and `p = Psi a`, the reduced operators are

```math
K_r=Q^TK_wQ, \quad M_r=Q^TMQ,
\quad K_{ar}=\Psi^TK_a\Psi, \quad M_{ar}=\Psi^TM_a\Psi,
```

```math
G_r=\Psi^TGQ, \quad \beta_h=\Psi^Tb.
```

The reduced coupled system is

```math
\begin{bmatrix}
K_r(1+i\omega\beta)-\omega^2M_r+i\omega\alpha M_r & -G_r^T\\
-\rho_0\omega^2G_r & K_{ar}-(\omega^2/c^2)M_{ar}
 +\kappa\beta_h\beta_h^T
\end{bmatrix}
\begin{bmatrix}q\\a\end{bmatrix}
=
\begin{bmatrix}Q^TF\\0\end{bmatrix}.
```

No diagonal reduced-matrix assumption is made. The enriched basis is not an
eigenbasis, so the projected `K_r` and `M_r` are used as computed. Each frequency is
then a small dense `numpy.linalg.solve`.

MUMPS is used for eigensolves and static attachment solves. It is not used for the
500 reduced frequency solves. Modes and attachments are built once and reused across
all frequencies and all ten bridge points.

Mode budgets are required to cover at least 1.5 times the analysis-band maximum.
Insufficient coverage or basis QC triggers deterministic mode-count escalation, up
to the configured retry limit.

## 12. Frequency Response and Peak Labels

Both body types store the same 500-point logarithmic grid from 20 to 5000 Hz. A
small floor is applied before the logarithm to prevent non-finite targets.

Solid peak labels start from in-band structural eigenfrequencies. Candidate strength
is estimated from bridge residues; the exact full harmonic response is evaluated at
candidate frequencies to label amplitude. Degenerate residues are grouped. Q follows
the Rayleigh damping relation.

Hollow peak labels are measured from an additional 4096-point log-frequency sweep
of the already-built reduced model. `scipy.signal.find_peaks` uses 3 dB prominence.
Peak frequency and amplitude are refined parabolically in log frequency, and Q is
estimated from half-power crossings.

For either body type, the strongest 32 peaks by amplitude are retained and then
stored in ascending frequency order. Arrays are zero padded and accompanied by a
boolean mask. A truncation flag records when more eligible peaks existed.

## 13. Dataset Orchestration and Quality Control

### 13.1 Immutable plan

Before FEM starts, `dataset_gen_mixed.py` serializes the configuration, contours,
materials, bridge layouts, frequency grid, splits, cases, source revision, and hashes
into `dataset_plan.json`. The canonical plan body receives a SHA-256 hash. Production
source files also receive implementation fingerprints.

An existing output directory may resume only when its plan and allowed source
fingerprints match. This prevents accidentally combining results generated under
different physical contracts.

### 13.2 Case execution

A case is one shape, body type, and material with ten bridge right-hand sides. CAD
and mesh artifacts are cached per shape/body. FEM runs in a subprocess with a case
timeout. Each attempt writes to staging, passes QC, and is then atomically committed.
The manifest is rebuilt from committed status records rather than appended during
workers.

Sharding assigns whole shapes to workers so processes do not contend for the same
geometry cache. A run policy may change execution order or defer selected material
slots, but does not mutate the immutable physical plan.

### 13.3 Fail-closed checks

Checks include finite arrays and scalars, exact frequency/schema dimensions, bridge
snap distance, geometry-plan consistency, modal band coverage, eigen residuals,
mass-orthonormality, reduced-basis condition, constant acoustic mode, port attachment
residual, reduced-model self-reconstruction, response units, peak validity, and
artifact hashes. A failed attempt never becomes a valid sample.

The completion policy records terminal failures and may publish a dataset containing
the successful cases. Counts remain in the readiness certificate and manifest
metadata; failures are not silently represented as numerical targets.

### 13.4 Splits

Train/validation/test assignment is shape-disjoint, nominally 70/15/15. Every body,
material, and bridge derived from one base contour remains in one split. When
datasets are combined, `nn_dataset.py` rejects identical geometry assigned to
different splits.

## 14. Neural Input and Target Contract

### 14.1 Shape raster

The contour is rasterized to a `96 x 96` grid. The normalization frame is a square
centred on the contour bounding box with side

```math
1.1\max(width,height).
```

The historical channel is binary occupancy. Optional variants use an outer-contour
signed-distance field and/or a separate soundhole field. Absolute size is deliberately
removed from the image and supplied through scalar features.

### 14.2 Scalar input

The standard physics input has 30 values:

- 10 orthotropic material properties;
- 6 bridge features: XYZ in mm, normalized XY, and Z/body-thickness;
- 12 geometry features: thickness, top plate, cavity volume, soundhole diameter,
  soundhole area and absolute XY, width, height, area, and normalized hole XY;
- 2 body-type indicators.

Optional relational inputs describe bridge-to-edge and bridge-to-hole geometry.
The extended set adds directional boundary distances, principal-frame location,
area moments, and local curvature. These remain a separate experimental input so the
30-value physics contract does not change.

### 14.3 Output and normalization

The main target is the 500-bin dB spectrum. Auxiliary labels contain peak frequency,
amplitude, Q, and mask for 32 slots. Input and target normalization statistics are
fit only on the training split. Supported target modes include global, per-frequency,
and per-frequency-per-body normalization.

Mirroring about X, Y, or both is available as an exact augmentation under the
axis-aligned orthotropic contract. Reflections change coordinate signs but not the
response of this linear, aligned material model.

## 15. Implemented Neural Architectures

No final architecture is declared. The code contains a family of controlled models:

- `full`: CNN shape encoder plus MLP physics encoder and a late-fusion spectrum head;
- `physics_only` and `shape_only`: modality ablations;
- `shape_id`: train-shape memorization diagnostic, not a valid unseen-shape model;
- `body_experts`: shared representation with solid/hollow output experts;
- `residual`: scalar baseline plus zero-initialized shape residual;
- `residual_film`: shape features FiLM-conditioned on case physics;
- `spatial`: multi-resolution convolutional feature maps queried at bridge location,
  with scalar, heatmap, bilinear-query, and hybrid conditioning options;
- `case_bridge`: one case-level spectrum plus bridge-specific corrections;
- `physics_wide`: capacity-matched scalar control;
- `relational`: scalar model augmented by explicit geometric relations;
- PCA-output variants with a fixed inverse projection back to the 500-bin curve.

The basic full model uses three convolutional blocks, a 128-dimensional shape latent,
a 64-dimensional physics latent, late fusion, and two 256-unit layers. This is a
baseline configuration, not a conclusion about the best representation.

Spectral decoders include direct regression, smooth-envelope plus detail residual,
and coupled peak/valley salience variants. Auxiliary heads can predict resonance
presence, frequency, amplitude, and log-Q.

## 16. Optimization and Spectral Evaluation

Training uses PyTorch, AdamW, and cosine learning-rate scheduling. Available losses
include normalized MSE or Huber loss, frequency-band balancing, multi-scale Gaussian
spectral loss in cents, difference-of-Gaussian detail loss, peak/valley focal loss,
peak count, modal peak labels, peak-band emphasis, PCA coefficient weighting, and
case/bridge consistency terms.

Evaluation reports broadband and bandwise error plus event metrics. Peaks and valleys
use the same detector backend, followed by Hungarian matching under frequency
tolerances expressed in cents. Precision, recall, F1/F2, prominence bands, and nearest
target diagnostics are reported. This separates smooth spectrum error from the harder
question of locating narrow resonant events.

## 17. Controlled Anchor Plan

The anchor planner imports the v6 generator without modifying it and assembles a
schema-compatible immutable plan.

- Block C reuses selected contours and samples thickness/top-plate/soundhole scalar
  cells. Redundant solid cells are collapsed because solid geometry ignores cavity
  and soundhole variables.
- Block A evaluates selected contours at scale factors `1.0`, `1.18`, and `1.40`,
  sharing normalized bridge and hole locations. Exact geometric scaling predictions
  apply to solids only, and fixed beta changes damping ratios.
- Block B normalizes multiple contours to a common `sqrt(area)` characteristic
  length and fixes the remaining explicit scalar/placement controls. Contour-derived
  width and height are not identical, so this is controlled contour variation rather
  than a proof that all geometry scalars are fixed.

Two source materials selected across the modulus distribution are copied byte-for-byte
to every anchor shape. Source splits are inherited by contour provenance. The planner
checks contour simplicity, complete soundhole containment, bridge margins, cavity
height, SPD materials, material identity, and split agreement before writing.

The anchor implementation is under active testing in this snapshot. The description
above documents its intended current controls and is not a certification of generated
anchor FEM results.

## 18. Implemented Reference and Ablation Paths

Several retained paths are useful for diagnosis but are not the v6 canonical target:

- `fenics_modal_admittance.py` can reconstruct a structural-only response from modal
  residues. It implements Rayleigh-equivalent damping and optional static residual
  flexibility. Residual flexibility is disabled in v6 because free-free rigid modes
  make naive subtraction of truncated modal compliance ill-conditioned unless the
  nullspace is explicitly deflated.
- `fenics_admittance_coupled.py` performs the full sparse D solve and is the reference
  for reduced hollow validation. It is too expensive for the bulk 500-frequency
  dataset path.
- The coupled acoustic code retains `closed` and direct `pressure_release` soundhole
  boundaries for debugging, plus an explicit-throat option. Direct pressure release
  removes neck inertance and is not the production A0 model.
- `fsi_coupling.py` contains both a multiphenicsx route and explicit conformal-facet
  assembly. The production operators use the audited facet integration path.
- Reduced structural `modal` basis and disabled acoustic port attachment are retained
  as ablations. Production uses static structural attachments and the acoustic port
  attachment.
- Air-only rigid-wall eigenmodes are diagnostic basis functions. With a
  frequency-dependent impedance port, A0 is a harmonic coupled-system resonance, not
  a pressure-release cavity eigenmode.

These alternatives should be labelled as reference or ablation results rather than
mixed with the production v6 response contract.
